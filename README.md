# Landa – demo

Klickbar prototyp av Landa, en guide för svenska familjer som flyttar till Costa del Sol: personlig flyttplan, kostnads- och skattekalkyl, vanliga frågor, kontakter och dokumentvalv.

Allt som fylls i sparas bara i besökarens egen webbläsare. Knappen för Landa Plus låser upp utan betalning. Skattesiffror och tidsfrister är utkast och ska inte användas som rådgivning.

Den riktiga appen ligger i ett privat repo.
